# How property prices are disclosed — listing transparency for /market

What a buyer can rely on about the price an agent advertises (behavior 153, Son 2026-11-04: the question Vietnamese buyers ask most). Each fact is one sentence its linked government page states, and no more. Victoria and NSW are the worked examples; each state sets its own rules. How to read the disclosed prices when comparing homes is owned by kb.comparables.reading-the-room; this doc only says what the law requires an agent to publish. NSW's announced new underquoting laws are not here: the government's own release describes them as legislation to be introduced, so they are not yet the rule.
